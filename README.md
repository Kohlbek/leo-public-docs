# LEO Household Support Platform

LEO is an experimental household-support platform exploring ways to simplify everyday technology, reduce caregiver workload, and preserve an older adult's independence.

This repository is the **sanitized public documentation surface** for the project. It intentionally excludes live household configuration, credentials, private device identifiers, personal information, camera imagery, network topology, local paths, and operational caregiver records.

## Public documentation

- [Project status](docs/project-status.md)
- [Architecture](docs/architecture.md)
- [Privacy and publication rules](SECURITY.md)

## Scope

Public materials may describe tested capabilities, design lessons, limitations, and generalized architecture. They do not provide the live operational configuration of any household system.

The operational implementation and private project records are maintained separately.
